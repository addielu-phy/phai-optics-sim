# AI × 幾何光學：從解題引導到互動模擬的建模學習

PhAI 共學圈 10/21 分享（講者：盧政良）使用的六個高中幾何光學互動模擬。每個頁面都是單一 HTML 檔（純 HTML + JavaScript + Canvas），不需建置，可直接開啟或離線使用。

線上版：https://addielu-phy.github.io/phai-optics-sim/

| 頁面 | 主題 |
|---|---|
| snell.html | 司乃耳定律 |
| total_internal_reflection.html | 全反射與光纖 |
| lateral_shift.html | 平行玻璃磚側位移 |
| apparent_depth.html | 視深與實深 |
| deviation_prism.html | 稜鏡偏向角與最小偏向角 |
| dispersion.html | 三稜鏡色散與彩虹 |

網址參數可預設滑桿，例如 `dispersion.html?rb=1&mag=6`。
